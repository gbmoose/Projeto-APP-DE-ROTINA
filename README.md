# Routine Flow

Aplicativo mobile da Bortolan Systems para melhorar a organização da rotina pessoal, profissional, dos estudos e dos treinos.

## Tecnologias

- React Native
- Expo
- TypeScript

## Primeira versão planejada

- Painel Meu Dia
- Tarefas por categoria e prioridade
- Hábitos recorrentes
- Estudos e treinos
- Progresso diário e semanal

## Executar localmente

1. Instale o Node.js LTS.
2. Execute `npm install`.
3. Execute `npm start`.
4. Leia o QR Code usando o Expo Go no celular.
